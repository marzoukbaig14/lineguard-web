# references/ — drop visual stills here

Screenshots of reference sites and real product/court imagery. An agent can
*see* images but generally can't load JS-heavy sites or watch video, so a still
frame teaches the look far better than a bare URL. See the notes at the bottom of
`../REFERENCES.md` for the reasoning.

## How to use

1. Drop image files (PNG/JPG) straight into this folder.
2. Name them `source_moment.ext` so it's obvious what each shows.
3. Add a one-line note under the matching reference in `../REFERENCES.md`, e.g.
   `- Screenshot: references/wingfield_hero.png — product hero framing`.

## What would help most right now

- `wingfield_hero.png` — Wingfield's product hero framing / finish (target look)
- `wingfield_feature.png` — a clean feature or spec moment from Wingfield
- `oura_feature.png` — an Oura feature/disclosure moment (calm, one idea at a time)
- `court_corner.png` — a real padel court from the back **corner**, low + side-on
  (the LineGuard angle / the moat)
- `court_wide.png` — a padel court wide shot for palette + material reference
- `ball_on_line.png` — a ball bouncing on/near a line (the "was it in?" moment)

Anything else that captures the vibe you want is welcome — more is better.
No need to optimize or resize; just get them in and I'll handle the rest.
